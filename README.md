# پروژه‌ی املاک — نسخه‌ی اول

## اول با یه مثال روزمره

تصور کن یه بنگاه املاک کوچیک داری با سه تا میز. میز اول هر روز صبح میره سایت دیوار و فایل‌های تازه رو برمی‌داره. میز دوم فایل‌ها رو مرتب می‌کنه؛ آگهی آژانس‌ها رو کنار می‌ذاره و فقط فایل‌های شخصی رو نگه می‌داره. میز سوم ماشین‌حساب دستشه؛ اگه مشتری گفت «سه میلیارد رهن کامل می‌خوام»، حساب می‌کنه که همون پول با رهن کمتر و اجاره‌ی ماهانه چقدر میشه. قانون بنگاه اینه که هر میز فقط کار خودش رو می‌کنه و به کار میزهای دیگه دست نمی‌زنه.

این برنامه دقیقاً همون بنگاه است، ولی توی کد.

## نقشه‌ی سه میز (ماژول‌ها)

| میز | اسمش توی کد | کارش |
|---|---|---|
| میز اول: گرفتن آگهی | ماژول گرفتن آگهی (⁦`fetch`⁩ — فچ) | با ⁦`API`⁩ (ای‌پی‌آی) رسمی دیوار حرف می‌زند؛ سه محله‌ی مهران، جلفا و دبستان و پنج دسته‌ی خرید/رهن آپارتمان، دفتر کار و زمین |
| میز دوم: فیلتر و ذخیره | ماژول آگهی‌ها (⁦`listings`⁩ — لیستینگز) | آگهی آژانس را با کلمه‌های ممنوعه کنار می‌گذارد، فقط آگهی شخصی را نگه می‌دارد و تکراری‌ها را دوباره ذخیره نمی‌کند؛ آگهی‌ها در فایل ⁦`data/listings.json`⁩ ذخیره می‌شوند |
| میز سوم: ماشین‌حساب | ماژول تبدیل (⁦`convert`⁩ — کانورت) | رهن کامل را به رهن کمتر + اجاره‌ی ماهانه تبدیل می‌کند |

روی این سه میز، یک «تلفن‌چی» هم هست: سرور ⁦`MCP`⁩ (ام‌سی‌پی) که سه ابزار دارد — ⁦`search-listings`⁩ ،⁦`convert-deposit`⁩ و ⁦`get-listing`⁩ — تا هوش مصنوعی بتواند مستقیم از برنامه استفاده کند. تلفن‌چی هیچ منطقی از خودش ندارد؛ فقط همان سرویس‌های سه میز را صدا می‌زند.

## ⚠️ یک عدد مهم که هنوز حدس است

نسبت تبدیل رهن به اجاره در این نسخه **۳٪** است. این عدد **حدس دستیار است، نه عدد واقعی بازار ماهان!** ماهان هنوز نسبت واقعی را نگفته است. این عدد فقط در **یک جا** هست — ثابت ⁦`RAHN_TO_EJARE_RATIO`⁩ در فایل ⁦`src/convert/convert.service.ts`⁩ — و وقتی ماهان نسبت واقعی را گفت، فقط همان یک خط عوض می‌شود و همه‌جای برنامه درست حساب می‌کند. این همان جواب سؤال فکری آخر فایل معماری است.

## چطور اجراش کنیم

```bash
npm install
npm run start:dev
```

برنامه روی ⁦`http://localhost:3000`⁩ بالا می‌آید. برای نسخه‌ی نهایی (بعد از بیلد):

```bash
npm run build
npm run start
```

## چطور تستش کنیم

اول یک دور تازه از دیوار بگیر و ذخیره کن:

```bash
curl -X POST http://localhost:3000/listings/refresh
```

جوابش شبیه این است: ⁦`{"fetched":228,"added":70,"skippedAgency":158,"total":70}`⁩ — یعنی ۲۲۸ آگهی خام آمد، ۷۰ تای شخصی ذخیره شد و ۱۵۸ تای آژانس کنار گذاشته شد.

بعد آگهی‌های ذخیره‌شده را ببین:

```bash
curl http://localhost:3000/listings
curl "http://localhost:3000/listings?district=دبستان"
curl http://localhost:3000/listings/ga3T0wlp
```

و تبدیل رهن به اجاره — مثال خود ماهان:

```bash
curl "http://localhost:3000/convert?rahn=3000000000&keep=1000000000"
```

جواب:

```json
{"fullRahn":3000000000,"keepRahn":1000000000,"convertedRahn":2000000000,"ejareMonthly":60000000,"ratio":0.03}
```

یعنی: از ۳ میلیارد رهن، ۱ میلیاردش می‌ماند و ۲ میلیاردش تبدیل می‌شود؛ ۲ میلیارد ضربدر ۳٪ می‌شود ماهی **۶۰ میلیون تومان** اجاره. اگر ⁦`keep`⁩ را ندهیم، یعنی همه‌ی رهن به اجاره تبدیل می‌شود (۳ میلیارد می‌شود ماهی ۹۰ میلیون).

## سرور ⁦`MCP`⁩ (ام‌سی‌پی)

سرور با ⁦`stdio`⁩ (استاندارد ورودی/خروجی) حرف می‌زند؛ یعنی خروجی معمولی برنامه فقط مال پروتکل است و هیچ‌چیز دیگری نباید آنجا چاپ شود. به همین خاطر **هرگز** با ⁦`npm run mcp`⁩ معمولی اجراش نکن — بنر خود ⁦`npm`⁩ خروجی را خراب می‌کند. یکی از این دو راه درست است:

```bash
npm run mcp --silent
npx ts-node src/mcp/mcp-server.ts
```

بعد از بیلد هم این راه هست:

```bash
node dist/mcp/mcp-server.js
```

سه ابزار سرور:

| ابزار | کارش |
|---|---|
| ⁦`search-listings`⁩ | جست‌وجوی آگهی‌های ذخیره‌شده، با فیلتر محله |
| ⁦`convert-deposit`⁩ | تبدیل رهن کامل به رهن کمتر + اجاره‌ی ماهانه |
| ⁦`get-listing`⁩ | جزئیات یک آگهی با شناسه‌اش |

برای وصل کردن به ⁦`Claude`⁩ (کلاد) یا ⁦`Cursor`⁩ (کرسر)، این تنظیم را به فایل تنظیمات ⁦`MCP`⁩ آن‌ها اضافه کن:

```json
{
  "mcpServers": {
    "realestate": {
      "command": "node",
      "args": ["/home/hatch/workspace/realestate-app/dist/mcp/mcp-server.js"]
    }
  }
}
```

## چی هنوز ساخته نشده

- **شیپور:** نسخه‌ی اول فقط دیوار است؛ شیپور ⁦`API`⁩ (ای‌پی‌آی) باز ندارد و بعداً اضافه می‌شود.
- **اعلان داخلی آگهی جدید:** الان آگهی‌های تازه فقط با ⁦`POST /listings/refresh`⁩ گرفته می‌شوند؛ اعلان خودکار هنوز نیست.
- **نسبت واقعی تبدیل:** عدد ۳٪ حدس است و باید با عدد واقعی ماهان عوض شود.
- **دیتابیس واقعی:** آگهی‌ها در فایل ⁦`data/listings.json`⁩ ذخیره می‌شوند؛ برای نسخه‌های بعد دیتابیس واقعی می‌آید.
- **پارس قیمت آگهی:** قیمت آگهی فعلاً فقط متن است و عدد رهن/اجاره از متن آگهی جدا نمی‌شود؛ تبدیل فعلاً با عددی که خودت می‌دهی کار می‌کند.
