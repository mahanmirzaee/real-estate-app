# موتور جست‌وجوگر ماهان — جست‌وجوی آگهی املاک (دیوار + شیپور)

نسخه‌ی فعلی: ۵٫۲

ابزار کاری یک مشاور املاک: آگهی‌های دیوار و شیپور را می‌گردد، فقط فایل‌های شخصی را نگه می‌دارد، رهن و اجاره را با نسبت واقعی بازار به هم تبدیل می‌کند، فایل مناسب هر مشتری را پیدا می‌کند و آگهی تازه را خبر می‌دهد.

## امکانات

- **دو منبع:** دیوار با ⁦`API`⁩ (ای‌پی‌آی) رسمی و شیپور با ⁦`API`⁩ (ای‌پی‌آی) عمومی؛ هر دو پشت یک قرارداد مشترک‌اند، پس اگر یکی خراب شد آن یکی کار می‌کند.
- **فیلتر شخصی:** آگهی آژانس با کلمه‌های ممنوعه کنار گذاشته می‌شود و فقط فایل شخصی در لیست می‌آید؛ آگهی آژانس فقط برای میانگین قیمت محله ذخیره می‌شود.
- **تبدیل رهن و اجاره با ۳٪:** نسبت واقعی بازار، تاییدشده؛ رهن کامل به رهن کمتر + اجاره‌ی ماهانه تبدیل می‌شود و برعکس.
- **مشتری‌یاب:** جمله‌ی فارسی مشتری را می‌خواند (نوع ملک، محله، سقف ودیعه و اجاره، امکانات) و فایل‌های مناسب را می‌آورد؛ با قانون و کلمه کار می‌کند، نه با هوش مصنوعی بیرونی.
- **دفترچه‌ی مشتری‌ها:** هر مشتری با خواسته‌اش ثبت می‌شود؛ بعد از هر تازه‌سازی، اگر فایل تازه‌ای به دردش خورد، چت وضعیت خبر می‌دهد و زیر کارت آن فایل هم نوشته می‌شود «این فایل مناسب مشتری فلانی است».
- **سرچ بودجه:** صفحه‌ی جدا؛ فایل‌هایی را می‌آورد که معادل رهن کاملشان زیر سقف باشد (با همان ۳٪).
- **اعلان آگهی تازه:** هر آگهی تازه با رویدادش در یک تراکنش نوشته می‌شود (اوت‌باکس)؛ هیچ فایل تازه‌ای گم نمی‌شود.
- **تاریخ انتشار:** بالای هر کارت هست و لیست تازه‌ترین اول است؛ برای دیوار از صفحه‌ی آگهی و برای شیپور از جزئیاتش.
- **میانگین محله با میانه:** جدا برای خرید و اجاره، حداقل ۳ نمونه؛ اگر متری فایل بیش از ۱۰٪ زیر میانه‌ی محله‌اش باشد، نشان «زیر قیمت» می‌خورد.
- **گالری عکس و امکانات:** عکس‌های آگهی با دکمه‌ی قبلی و بعدی؛ پارکینگ و انباری و آسانسور با رنگ سبز (دارد)، قرمز (ندارد) و خاکستری (معلوم نیست).
- **ورود با کد:** ورود با کد شش‌رقمی؛ نشست ۳۰ روزه؛ نقش کاربر و مدیر هست ولی بخش مدیریت هنوز ساخته نشده است.
- **رابط گرافیکی:** تم تیره با طلایی، پنل درختی خرید و اجاره، چک‌باکس چندتایی محله، تایمر ۳۰ دقیقه و دکمه‌ی تازه‌سازی، چت وضعیت، صفحه‌بندی ۱۰تایی و جداکننده‌ی هزارگان فارسی.
- **سواگر و سرور ⁦`MCP`⁩ (ام‌سی‌پی):** همه‌ی آدرس‌ها با سواگر قابل تست‌اند؛ سرور ⁦`MCP`⁩ (ام‌سی‌پی) سه ابزار دارد تا هوش مصنوعی مستقیم از برنامه استفاده کند.

## معماری

### تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| زبان و چارچوب | ⁦`TypeScript`⁩ (تایپ‌اسکریپت) با ⁦`NestJS`⁩ (نست‌جی‌اس) ۱۱ |
| دیتابیس | ⁦`PostgreSQL`⁩ (پستگرس‌کیوال) ۱۶ با ⁦`Prisma`⁩ (پریزما) ۷ |
| حافظه‌ی موقت و صف | ⁦`Redis`⁩ (ردیس) با ⁦`BullMQ`⁩ (بول‌ام‌کیو) |
| اجرا | ⁦`Docker Compose`⁩ (داکر کامپوز)؛ برنامه روی درگاه ۳۰۰۰ |

### ماژول‌ها

| ماژول | کارش |
|---|---|
| ⁦`fetch`⁩ (فچ) | گرفتن آگهی از دیوار و شیپور؛ هر منبع یک کلاس جدا پشت قرارداد مشترک، با فکتوری |
| ⁦`listings`⁩ (لیستینگز) | فیلتر آژانس، ذخیره در دیتابیس، قیمت و متراژ و امکانات، مشتری‌یاب، میانگین محله |
| ⁦`convert`⁩ (کانورت) | تبدیل رهن و اجاره با نسبت ۳٪؛ نسبت فقط در یک ثابت است |
| ⁦`scheduler`⁩ (اسکجولر) | تازه‌سازی خودکار هر ۳۰ دقیقه + یک بار موقع روشن شدن |
| ⁦`notifications`⁩ (نوتیفیکیشنز) | اعلان آگهی تازه با اوت‌باکس |
| ⁦`clients`⁩ (کلاینتس) | دفترچه‌ی مشتری‌ها و تطبیق فایل با مشتری |
| ⁦`settings`⁩ (ستینگز) | محله‌های قابل‌تغییر در دیتابیس |
| ⁦`auth`⁩ (آث) | ورود با کد شش‌رقمی و نشست |
| ⁦`mcp`⁩ (ام‌سی‌پی) | سرور ⁦`MCP`⁩ (ام‌سی‌پی) با سه ابزار |

### جریان داده

زمان‌بندی هر ۳۰ دقیقه ماژول گرفتن آگهی را صدا می‌زند؛ هر منبع آگهی‌های خام را می‌آورد؛ فیلتر آژانس‌ها را کنار می‌گذارد؛ آگهی شخصی تازه در دیتابیس ذخیره می‌شود و در همان تراکنش یک رویداد اوت‌باکس هم نوشته می‌شود؛ لیست آگهی‌ها ۶۰ ثانیه در ردیس می‌ماند و بعد از هر تازه‌سازی پاک می‌شود.

### مدل داده

| جدول | چی نگه می‌دارد |
|---|---|
| ⁦`Listing`⁩ (لیستینگ) | آگهی: شناسه، عنوان، توضیح، قیمت‌ها، متراژ، محله، منبع، تاریخ انتشار، امکانات، عکس‌ها |
| ⁦`OutboxEvent`⁩ (اوت‌باکس ایونت) | رویداد آگهی تازه، در همان تراکنش ذخیره‌ی آگهی |
| ⁦`Client`⁩ (کلاینت) | مشتری: اسم، نوع، سقف بودجه، محله، امکانات خواسته‌شده، یادداشت |
| ⁦`AppUser`⁩ (اپ‌یوزر) | کاربر: اسم، کد شش‌رقمی، نقش |
| ⁦`AppConfig`⁩ (اپ‌کانفیگ) | تنظیمات، از جمله فهرست محله‌ها |

### قانون تبدیل ۳٪

نسبت تبدیل رهن به اجاره **۳٪** است — عدد واقعی بازار، تاییدشده. معادل رهن کامل یعنی رهن + اجاره تقسیم بر ۰٫۰۳؛ مثلاً ۱ میلیارد رهن + ۳۰ میلیون اجاره یعنی معادل ۲ میلیارد رهن کامل. این عدد فقط در یک ثابت است: ⁦`RAHN_TO_EJARE_RATIO`⁩ در ⁦`src/convert/convert.service.ts`⁩.

## آدرس‌ها

### ⁦`REST`⁩ (رست)

| آدرس | کارش |
|---|---|
| ⁦`GET /listings`⁩ | فهرست آگهی‌ها با فیلتر محله، نوع و منبع |
| ⁦`GET /listings/:token`⁩ | جزئیات یک آگهی |
| ⁦`GET /listings/budget?target&max`⁩ | سرچ بر اساس بودجه با معادل رهن کامل |
| ⁦`POST /listings/refresh`⁩ | یک دور تازه‌سازی دستی |
| ⁦`POST /listings/match`⁩ | مشتری‌یاب با جمله‌ی فارسی |
| ⁦`GET /clients`⁩ ،⁦`POST /clients`⁩ ،⁦`DELETE /clients/:id`⁩ ،⁦`GET /clients/:id/matches`⁩ | دفترچه‌ی مشتری‌ها |
| ⁦`GET /settings/districts`⁩ ،⁦`POST /settings/districts`⁩ ،⁦`DELETE /settings/districts/:id`⁩ | محله‌ها |
| ⁦`GET /notifications`⁩ ،⁦`POST /notifications/read-all`⁩ | اعلان‌های آگهی تازه |
| ⁦`GET /scheduler/status`⁩ | وضعیت زمان‌بندی و دور آخر |
| ⁦`GET /convert?rahn&keep`⁩ | تبدیل رهن به اجاره |
| ⁦`GET /`⁩ | رابط گرافیکی «موتور جست‌وجوگر ماهان» |
| ⁦`GET /api`⁩ | صفحه‌ی سواگر (بعد از ورود) |

همه‌ی آدرس‌ها پشت ورودند؛ فقط ⁦`/login`⁩ باز است.

### سرور ⁦`MCP`⁩ (ام‌سی‌پی)

| ابزار | کارش |
|---|---|
| ⁦`search-listings`⁩ | جست‌وجوی آگهی‌های ذخیره‌شده با فیلتر محله |
| ⁦`convert-deposit`⁩ | تبدیل رهن کامل به رهن کمتر + اجاره‌ی ماهانه |
| ⁦`get-listing`⁩ | جزئیات یک آگهی با شناسه‌اش |

اجرا با ⁦`npm run mcp --silent`⁩ (هرگز بدون ⁦`--silent`⁩ اجرا نکن؛ بنر ⁦`npm`⁩ خروجی پروتکل را خراب می‌کند).

## اجرا

```bash
git stash
git pull
git stash pop
docker compose up -d
npm install
npx prisma generate
npx prisma migrate deploy
npm run build
npm start
```

- دستور ⁦`npm run db:seed`⁩ را نزن؛ کاربر و کد ورودت از قبل ساخته شده است.
- اگر فایل ⁦`docker-compose.yml`⁩ را روی لپ‌تاپ خودت عوض کرده‌ای (درگاه دیتابیس ۵۴۳۳ و درگاه ردیس ۶۳۷۹)، با ⁦`stash`⁩ و ⁦`stash pop`⁩ تغییر خودت نگه داشته می‌شود؛ هرگز ⁦`git checkout -- docker-compose.yml`⁩ نزن.
- اگر برنامه‌ی قدیمی بالا آمد، اول ⁦`dist`⁩ و فایل ⁦`tsconfig.build.tsbuildinfo`⁩ را پاک کن و دوباره ⁦`npm run build`⁩ بزن.
- ویترین روی ⁦`http://localhost:3000`⁩ است و اول صفحه‌ی ورود را نشان می‌دهد؛ سواگر روی ⁦`http://localhost:3000/api`⁩ است.

برای توسعه:

```bash
npm install
npm run start:dev
```
